The rules of the trial: the model's weights, coefficients, and betting threshold were frozen before this page existed. Each day's verdicts are logged at the listed price and never rewritten, first-five ties settle as pushes, and rain-shortened games are void. If the line goes up, the model is beating the market; if it doesn't, you're watching an honest negative result in real time — which is rarer than a picks site, and worth more.
